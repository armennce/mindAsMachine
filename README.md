This was project was inspired by the functionalist philosphy of computationalism. Computationalism states the following : our mind acts like an information processing system (IPS) and our thoughts, like the application of a set of rules, that would be specific to each are of our brain. If we cif we compare it to maths, these would litterly be represented by maps, sets and function. Different results 
Thus the goal of this project will be to modelize the link between the different areas of our brain and the global and dynamic parameters that model these functions according to the context (mood, hormones, stimulus, etc).
